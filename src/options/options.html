Description

The AI writes an intro and a Key Features list from the product's title, variants, specifications and the supplier's text (leaving out factory and company info). Your Specifications table goes underneath. The bot uses it too.

You can leave the key fields empty and put the keys in the .env file in the extension folder instead (see .env.example).

Without AI, the description is the Specifications table plus, if ticked below, the supplier's own description.
